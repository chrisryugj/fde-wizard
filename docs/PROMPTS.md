# 따라 하기 프롬프트

Claude Code에 그대로 붙여 넣어 쓰면 됩니다. 이 저장소를 클론한 폴더에서 Claude Code를 열고 시작하세요.

## 1. 내 캐릭터로 바꾸기 (이 킷을 쓸 때)

```
ref/photo.jpg 가 내 사진이야. 이 사진을 보고 scripts/params.py 숫자만 고쳐서
나랑 닮은 치비 캐릭터로 바꿔줘.

- 고칠 때마다 scripts/prev.sh head face front q34 side 로 렌더해서
  tmp/sheet_head.png 에 사진이랑 나란히 놓고 비교해
- 머리 모양은 HAIR_LOCKS(다발마다 방위·고도·띄움), 눈웃음은 FACE['eye_smile'],
  색은 COLORS 에서 바꿔
- params.py 의 PROFILE 에 내 소속·이름도 넣어줘
- 닮았다고 판단되면 blender -b -P scripts/build_rig.py 로 리그까지 다시 지어
```

## 2. 처음부터 만들기 (킷 없이)

```
이 사진 보고 나를 귀엽고 깜찍한 치비 3D 캐릭터로 만들어줘.
모델링, 리깅, 포즈, 10초 애니메이션까지 전부 블렌더 파이썬으로.

규칙:
1. 블렌더는 화면 없이 돌려 (blender -b -P script.py). 나는 블렌더를 안 켤 거야
2. 치수·색·머리 모양은 params.py 한 파일에 숫자로 모아
3. 부품은 잘게 나눠 (머리카락은 다발 여러 개로)
4. 부품을 바꿀 때마다 정면·45도·옆을 렌더해서 사진이랑 나란히 놓고 비교한 다음 고쳐
5. 리그는 팔다리 IK, 표정은 교체 부품(눈웃음·벌린 입)을 숨겨 뒀다가 켜는 방식으로
6. 리그를 지은 뒤 '뼈에 안 붙은 부품이 있으면 빌드 실패' 검사를 넣어
7. 완성 영상은 몇 장 샘플 말고 전 프레임을 타일로 펼쳐서 겹침·잘림을 검수해
```

## 요령

- **"사진이랑 나란히 비교해"** 한 마디가 제일 효과가 큽니다. Claude Code는 렌더 이미지를 직접 보고 스스로 고칩니다.
- **버그는 증상을 시간과 함께** 말하세요. "24초쯤 모자랑 머리 비침"처럼요.
- **감으로 고치지 말고 재라고** 하세요. "얼마나 뚫었는지 숫자로 재서 0 이하로 만들어"가 두 번 헛짚은 걸 끝냈습니다.
